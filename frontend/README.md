# ILES React Frontend

This is the React frontend for the CSC 1202 Internship Logging & Evaluation System (ILES).

It includes:

- Dashboard overview
- Weekly logbook workflow
- Academic evaluation and weighted scoring
- Reports and deliverable tracking
- Role and workflow settings

## Run Locally

```bash
npm install
npm run dev
```
